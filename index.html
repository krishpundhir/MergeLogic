In-Place Merge — O(1) Auxiliary Space

Merging Two Sorted Portions of One Array

One array. No temporary array. Only a few pointers.

    ✓

    The current merge step is complete

    The merged portion arr[0..7] is now sorted. The algorithm continues with:

    merge(arr, left, i - 1, right)
= merge(arr, 4, 7, 9)

    With left = 4, i = 8 and right = 9, this call merges [1, 6, 7, 8] with the remaining right portion [3, 5].

    Complexity

    Auxiliary space: O(1)

    Why? No temporary array is created. Only a constant number of variables (left, mid, i, right, count) are used, no matter how long the array is.

    The array itself is modified in-place.

    Time is a separate question

    O(1) describes extra memory, not running time. Swapping and shifting elements one position at a time can take quadratic time in the worst case, because an element may travel across many positions.

    The next merge call is the last thing the function does, so it can be written as a loop and the call stack does not grow.
